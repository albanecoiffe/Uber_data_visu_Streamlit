# Uber Data Visualization with Streamlit 

[Streamlit page](https://uberdatavisuappwithpython.streamlit.app/)    

This project uses Streamlit to create an interactive dashboard for exploring Uber trip data from January 2015 in New York. The goal is to provide dynamic visualizations and analyses of various aspects of the data, such as passenger counts, tips, trip distances, and more.

## 📊 Key Features
- Hourly Data Visualization: Graphs (line and bar charts) displaying passenger count, trip count, tips, and distances per hour.
- Specific Time Statistics: Detailed statistics at 10 PM and 4 AM, including total distance, number of passengers, tips, and trip count.
- Fare Distribution by Distance: Graphs showing the distribution of average fares based on trip distance.
- Average Fare Analysis: Hourly averages of fares, tips, and total trip amounts.
- Average Trip Speed: Visualization of the average speed of trips per hour.
- Trip Maps: Interactive maps showing pickup and drop-off points with two views: a simple map and a 3D map using Pydeck.

## 🛠️ Technologies Used
- `Python`: Primary programming language.
- `Streamlit`: Framework for building the interactive dashboard.
- `Pandas`: Used for data manipulation.
- `Altair & Seaborn`: Libraries for data visualization.
- `Pydeck`: For creating interactive geospatial visualizations.
- `Matplotlib`: Used for additional visualizations.
